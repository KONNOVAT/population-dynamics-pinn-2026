# Модель межвидовой конкуренции: Tsit5 и PINN

Ноябрьский вычислительный эксперимент воспроизводится командой из корня репозитория:

```powershell
julia --project=code/ode code/ode/competition_model.jl
```

Скрипт выполняет аналитическую и численную проверку трёх режимов конкуренции:

- устойчивое сосуществование;
- вытеснение вида 2 видом 1;
- бистабильность с двумя областями притяжения.

Для каждого режима программа:

1. вычисляет стационарные точки;
2. определяет устойчивость по собственным значениям матрицы Якоби;
3. решает систему методом `Tsit5` для четырёх начальных условий;
4. проверяет неотрицательность решения и сходимость к ожидаемому равновесию;
5. сохраняет временные графики, фазовые портреты и две сводные CSV-таблицы.

Результаты записываются в `code/ode/results/classical`.

Декабрьский PINN-эксперимент запускается так:

```powershell
$env:PINN_SEED='42'
$env:PINN_MAXITERS='1000'
$env:PINN_T_END='5.0'
julia --project=code/ode code/ode/competition_pinn.jl
```

Скрипт `competition_pinn.jl` использует `NeuralPDE.NNODE`, сеть Lux из четырёх
скрытых слоёв по 64 нейрона, функцию активации `gelu`, оптимизатор
`Adam(0.01)` и интервальную стратегию обучения. Параметры запуска задаются
переменными окружения `PINN_REGIME`, `PINN_SEED`, `PINN_MAXITERS`,
`PINN_T_END`, `PINN_VERBOSE` и `PINN_SAVE_PLOTS`.

Основной контроль выполнен на интервале $t\in[0,5]$ для трёх режимов и трёх
инициализаций сети (`seed = 11, 42, 73`). Дополнительно проверены другое
начальное условие в режиме сосуществования и противоположная область
притяжения при бистабильности. Сводная таблица повторных запусков создаётся
командой:

```powershell
julia code/ode/summarize_pinn_metrics.jl
```

Результаты записываются в `code/ode/results/pinn`. Это промежуточный этап:
качество на полном интервале до $t=15$--$20$ и более строгий протокол
сравнения времени требуют отдельного эксперимента.
