# Pluto: модели Лотки — Вольтерры и конкуренции

В этой папке находится очищенная воспроизводимая версия среды из `LV.zip`.
Контрольная версия Julia — **1.13.3**. Пакеты закреплены файлами
`Manifest.toml`; сам Pluto установлен в отдельном окружении `pluto_env`.

Основные версии:

- Pluto 1.1.0;
- NeuralPDE 7.5.0;
- Lux 1.31.5;
- OrdinaryDiffEq 7.8.1;
- OptimizationOptimJL 0.4.23;
- Plots 1.41.7.

## Запуск из терминала PyCharm

Из корня проекта:

```powershell
& 'C:\Users\konno\AppData\Local\Programs\Julia-1.13.3-portable\julia-1.13.3\bin\julia.exe' --project=code/pluto/pluto_env code/pluto/start_competition.jl
```

После запуска откройте в браузере `http://127.0.0.1:1234`: Pluto загрузит
`competition_pinn.jl`. Для обычной модели Лотки — Вольтерры вместо последнего
файла укажите `code/pluto/start_lv.jl`. Сервер слушает только локальный адрес
`127.0.0.1`, поэтому для локального запуска проверка секретной ссылки отключена.

## Проверка без браузера

Полный расчёт конкуренции и запись численных метрик выполняются командой:

```powershell
& 'C:\Users\konno\AppData\Local\Programs\Julia-1.13.3-portable\julia-1.13.3\bin\julia.exe' --project=code/pluto code/pluto/verify_competition.jl
```

Результаты сохраняются в `code/pluto/results/competition`:

- `training_attempts.csv` — каждая фактическая попытка обучения;
- `run_summary.txt` — версии, максимальные ошибки и число повторных обучений;
- `image/*.png` — семь графиков из Pluto-блокнота.

## Что изменено в схеме обучения

В старом эксперименте одна сеть обучалась сразу на всём временном интервале,
из-за чего приближение могло сходиться к неудовлетворительному решению. В
исправленном блокноте применены следующие меры:

1. численности представлены как `Nᵢ = Kᵢ exp(zᵢ)`, поэтому результат PINN
   остаётся положительным;
2. интервал `0–20` разбит на окна длиной 2;
3. на каждом окне используется BFGS, `GridTraining(0.05)` и не более 600
   итераций;
4. конечное состояние одного окна становится начальным условием следующего;
5. если критерий `max |PINN − Tsit5| / K < 0.01` не выполнен, предусмотрена
   вторая схема: окно 1, адаптивное интегрирование невязки и 1000 итераций;
6. эталон Tsit5 дополнительно сверяется с Vern9.

Данные Tsit5 не входят в loss при обучении. Они используются только после
обучения для независимой оценки точности.
