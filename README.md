# ВКР магистра — Коннова Т.

**Тема:** «Сравнительное исследование численных и нейросетевых методов моделирования динамики конкурирующих популяций»

**Научный руководитель:** Штепа К. А.

## Структура

```
vkr/          — текст ВКР (LaTeX)
code/         — программная реализация (Julia)
  ode/        — классическая модель конкуренции (ОДУ)
  pluto/      — воспроизводимые Pluto-блокноты PINN
  pde/        — диффузионная модель конкуренции (УЧП)
articles/     — статьи для публикации
misc/         — материалы прошлых лет (статья ИТТММ, код)
sources/      — собранные источники и аннотации
```

## Модели

- **Модель 1 (ОДУ):** классическая модель межвидовой конкуренции Лотки-Вольтерры
- **Модель 2 (УЧП):** диффузионная модель конкуренции (reaction-diffusion)

## Инструменты

- Julia, NeuralPDE.jl, DifferentialEquations.jl, Lux.jl
- LaTeX для текста ВКР
