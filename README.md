# ВКР магистра — Коннова Т.

**Тема:** «Сравнительное исследование численных и нейросетевых методов моделирования динамики конкурирующих популяций»

**Научный руководитель:** Штепа К. А.

## Структура

```
vkr/                    — текст ВКР и библиография
  index.qmd             — титульная часть и общая сборка
  chapter1.qmd          — теоретическая глава
  chapter3.qmd          — вычислительный эксперимент
  lit.bib               — библиографическая база
code/                   — программная реализация на Julia
  ode/                  — скрипты ОДУ и пакетные эксперименты
    results/classical/  — результаты классических методов
    results/pinn/       — метрики и графики PINN
  pluto/                — интерактивные Pluto-блокноты
    competition_pinn.jl — основной блокнот модели конкуренции
    lv_pinn.jl          — учебный пример «хищник — жертва»
    results/competition — проверенные результаты основного блокнота
sources/                — обзор литературы и рабочие источники
```

Импортированные исходные материалы и личные учебные заметки хранятся локально
и исключены из репозитория. Воспроизводимые очищенные версии кода находятся в
`code/ode` и `code/pluto`.

## Модели

- **Модель 1 (ОДУ):** классическая модель межвидовой конкуренции Лотки-Вольтерры
- **Следующий этап:** диффузионная модель конкуренции (reaction-diffusion, УЧП)

Для ОДУ рассмотрены четыре режима: победа первого вида, победа второго вида,
сосуществование и бистабильность. Решения PINN сравниваются с `Tsit5`, а
эталонный расчёт дополнительно проверяется методом `Vern9`.

## Инструменты

- Julia, NeuralPDE.jl, DifferentialEquations.jl, Lux.jl
- Pluto.jl для воспроизводимых интерактивных экспериментов
- Quarto/LaTeX для текста ВКР

Инструкции по запуску и описание результатов приведены в
[`code/pluto/README.md`](code/pluto/README.md).
